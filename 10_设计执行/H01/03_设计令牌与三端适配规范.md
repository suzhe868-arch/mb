# H01-2｜已确认方向下的三端设计令牌与响应规范

> 视觉方向：`暖白底 + 石墨文字 + 克制金色强调`，用户已确认；**HEX 只是当前设计候选**。
> 设计权威：最新 H01 视觉方向确认交接单 + PDM-10/18/20/21/22 Final + Current IA/Low-Fi。
> 本文件是 Design System 设计规格，不是正式前端落地授权。

## 1. 语义令牌是唯一色彩来源

- 机器可读权威设计源：`设计令牌_候选.json` 的 `semantic.*`；
- 可供 CSS/设计源使用的映射：`设计令牌_语义.css`（与 JSON 对应）。
- 关键颜色不写进页面每个 shape：设计图使用 `var(--semantic-...)` 命名引用；静态 SVG 评审稿为该 token 的渲染快照，有些 SVG 预览环境会内嵌**由同一 JSON 生成的变量声明**保证独立打开可见。改主色时由 token 重新导出评审 SVG，而不是逐页重画。
- `semantic.brand.primary = #80611F`，`semantic.brand.subtle = #F1E7D1`，`semantic.brand.onPrimary = #FFFFFF`，点缀浅金 `#C4A66A`。
- `semantic.surface.canvas = #F8F6F1`，`semantic.surface.panel = #FFFFFF`，`semantic.surface.soft = #F6F2E9`。
- `semantic.foreground.primary = #25282B`，`semantic.foreground.secondary = #6B6860`。
- `semantic.border.subtle = #E5E0D7`，`semantic.border.strong = #C5BBA9`。
- `semantic.feedback.success/warning/danger/focus` 独立，不允许用金色混充成功/警告/错误。

## 2. 静态颜色对比度
见 `H01_设计对比度核验记录.md`。当前主色 #80611F + 白字为 5.76:1；石墨 + 暖白为 13.72:1。完整的色彩组合/真机检查尚未执行。

## 3. 共用排版
- 中文字体优先由操作系统无衬线字体提供，不把字体文件写入设计资产。
- 移动标题 20～22px、车型标题 15～17px、正文 13～15px、辅助 12～13px；行高 1.35～1.55；严禁以 10px 替代真实移动文字密度。
- 间距 `4/8/12/16/20/24/32/40/48px`；移动横边距 16px、触控目标建议不小于 44×44px；卡片圆角 12px；PC 表格每行参考 48px。
- 不通过在车型标题右侧开整列价格撑大车辆卡；主车标题行优先使用固定宽度溢出省略与详情继续阅读。
- 无真实字段时隐藏该字段整项，不用捏造“暂无”文本补充数据。

## 4. 三端各自重点

| 端 | 页面密度 | 导航/布局 | 权限 |
| --- | --- | --- | --- |
| C | 搜索/主筛选连续可用，卡片车辆标题/地区/里程信息清楚 | 390×844 参考，两种 C01 顶部态，底部三项“车源/帮我找车/我的” | 只呈现 Customer Safe；普通批发列表不泄露数字价 |

## 5. UI 状态与 A 复审
加载/空/错误/提交中/已确认/对象冲突/无权字段隐藏/有权对象禁用沿用 H01-3 组件矩阵。颜色仅提供视觉反馈，永远不取代真正服务端的权限检查与业务 Guard。小程序实际滚动阈值/过渡时长留 H03，H01 不造运行行为。
