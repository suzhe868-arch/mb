## 2. 页面与状态追溯

### C01 — 车源列表
- 来源：`CURRENT/CLIENT/C01/C01-S01-NORMAL.svg`，另有 S02 LOADING/S03 EMPTY/S04 ERROR；PDM-20/10。
- 版式：搜索、合法分类/筛选、车辆图片摘要、普通列表不泄露批发数字价、详情入口、底部导航。
- 关键负例：客户 LIMITED 不因列表预加载获得价格解锁；没有“点击查价”独立动作。

### C01-01 — 客户车辆详情
- 来源：`CURRENT/CLIENT/C01-01/C01-01-BR-NORMAL-DEFAULT.svg` 及 LOCK_REQUEST_PENDING/LOCKED_BY_SELF/LOCKED_BY_OTHER/WAITLISTED/CLOSED_NOT_LOCKABLE 的当前合法分支；PDM-10/18/20。
- 当前 SVG 展示 **额度已耗尽、未有该周期解锁且车辆有合法价** 的价格占位分支。另一个 `价格咨询` 是车辆无合法数字价，不能混用。
- 底部动作独立 `收藏｜咨询｜锁车`；锁车只创建或复用申请。分享直达变体需增加 `更多车源`，**此次仅默认入口，不宣称覆盖分享分支**。
- 实际批准或冲突后的终态差异由 `H01-3` 组件矩阵注明，H02 才制作完整逐状态页面。

### C02 — 找车意向
- 来源：`CURRENT/CLIENT/C02/C02-S01-NORMAL.svg` / PDM-11/12/20。
- 该样稿只展示表单布局、等级权益告知与意向提交骨架。**不代表普通客户具备正式匹配/推荐资格**。
- 文案是视觉评审草稿；H02 必须核对 Current IA 对动作资格、拒绝与恢复的具体投影。

### E01 — 员工工作台
- 来源：`CURRENT/EMPLOYEE/E01/E01-S01-NORMAL.svg`；4S 变体 `E01-S4S01-NORMAL.svg`；PDM-21。
- 接客状态 E01 顶部唯一开关；强待办、Customer Opportunity、Source Radar 独立。
- 图示仅为名邦员工合法有权视图；4S 不显示 LockRequest 业务入口，非单纯禁用。

### E02-02 — 人工车录入
- 来源：`CURRENT/EMPLOYEE/E02-02/E02-02-S01-NORMAL.svg`，`E02-02-S07-DRAFT_RESUME.svg`；PDM-06/21。
- 空白进入不建草稿；有效输入后自动生成/保存，更多菜单进入草稿车源列表。
- SVG 使用 `已自动保存` 的反馈示例；禁止额外“保存草稿”按钮及单草稿恢复弹层。
- 4S 只在同一员工 App 内做固定 4S 来源的裁剪；此图非 4S 变体全量。

### E07-08 — LockRequest 审批
- 来源：`CURRENT/EMPLOYEE/E07-08/E07-08-BR-PENDING.svg`；PDM-18/21。
- 仅当前具备 Lock 审核 capability 的名邦员工可见；4S hard DENY。
- 按服务端 PENDING 最长 6 小时；同意/拒绝提交必须重验资格和车辆状态。SVG 不模拟真实倒计时，不能作为可运行审批 UI。

### P02 — 后台车源管理
- 来源：`CURRENT/PC/P02/P02-S01-NORMAL.svg`；PDM-22、Current IA。
- PC 表格/工具条的静态模板仅用于信息密度和权限投影。受控动作/数据返回需当前身份+权限+数据域+对象状态复核。
- System Admin 的控制平面身份不默认授员工业务权限；4S 默认不能进入 PC；无权入口/动作不渲染。
- 不添加旧 Collector 电话连接 Base URL / Phone Path 与测试取号功能。
