## 3. 客户端视觉重点核验

- 卡片左侧示例图片，右侧实际合法车型、首次上牌/里程/地区/当前上架时间等信息（部分字段取值缺失应整项隐藏）；价格回到信息区下半段，不开独立宽列。
- **没有**宣传型“严选/已检测/高性价比/官方直营/质保天数”无事实标签。
- 详细身份/权限边界：普通 LIMITED 在 JYT 批发列表不见数字价；主动合法进入详情有余额则自动解锁；已耗尽显示 `--万`；真无数字价为“价格咨询”；UNLIMITED 有价直接展示。
- 三项底部一级导航不能因为收藏业务仍存在而扩展成四项。
- 首页来源切换、地域、搜索、排序和滚动位置正式行为在 PDM-20；H01 不自造手势阈值或运行状态。

## 4. 视觉评审与残余事项

- 已确认：暖白/石墨/克制金色 **方向**；待确认：具体金色色值/有授权的官方 Logo/样稿满意度。
- 本轮设计系统用 JSON semantic + CSS + SVG 中的 `var(--semantic-...)` 语义引用；静态 SVG 使用同 JSON 值生成变量声明以便独立预览；后续品牌调色需重导出快照，但不用逐页手动移动布局。
- 真机浏览器渲染/真实字体宽度/动态缩放/低网速图片/键盘交互/完整 WCAG：`NOT_RUN`。
- A 审核通过前，`H01` 最终保持 `READY_FOR_A_REVIEW`，不更新 main 状态也不进入 H02。
