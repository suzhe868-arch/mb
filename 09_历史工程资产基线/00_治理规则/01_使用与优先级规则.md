# Legacy Engineering Baseline｜使用与优先级规则

## Authority 顺序

1. PDM-01～25 Final
2. Current IA
3. Current Low-Fi
4. Current Engineering Baseline / Work Order
5. Legacy Engineering Baseline
6. 更早历史资料

## 使用规则

- Legacy 只能作为 Engineering Delta 的输入，不能作为 Current Product Authority。
- 任何旧 Schema、API、权限、状态机、页面或测试，在复用前必须与当前 Authority 对照。
- 旧资产必须按 `KEEP_DATA / KEEP_CANDIDATE_VERIFY / MODIFY_REQUIRED / ADD_REQUIRED / DEPRECATED_LOGIC_REFERENCE / REFERENCE_ONLY` 分类。
- 真实车型数据、通用 Migration/Test/Contract 工具优先保留，但仍需校验当前字段与语义。
- 冲突时无条件以上层 Authority 为准。
- IA / Low-Fi 未完成冻结前，不因旧工程资产存在而提前视为 Current Engineering Baseline。
- 后续统一工程施工包应由“PDM Final + Current IA + Current Low-Fi + Legacy Engineering Delta”生成。

## Collector 边界

采集端为独立已运行系统，不在本项目范围内重写。名邦只负责最终 Integration API Contract、鉴权、错误码、幂等、联调说明及名邦侧实现。
