## 三、安全约束

- 仅接受 `APP_ENV=test`、`NODE_ENV=test`、`API_HOST=127.0.0.1`、精确隔离 consent 与固定的 `f05_catalog_test/f05_catalog_ci` 连接目标。
- 必须通过真实 PostgreSQL 16、非超级用户和完整现有测试 schema 检查。
- 员工凭证只从进程环境传入，不落盘、不写日志；员工会话必须由真实测试数据提供，不签发正式 Issuer。
- 每个进程只允许一个 tick 在途；批量上限为 10，默认批量 10；实际测试使用更小批量检验边界。
- 调度器只调用现有 `runOnce()`；既有 worker 的 generation CAS、lease stamp、幂等 event key、失败次数与数据库退避语义不另行复制。
- 进程退出后不保存内存待办；PostgreSQL 队列与租约是恢复依据。
- 不访问真实 JYT、Collector、CDN、对象存储、飞书或生产服务，不触发正式交易、推荐、优先级或可见权授予。
- 日志只记录状态、计数、耗时和稳定错误码；禁止客户标识、电话、token、密码、原始敏感 Payload 与数据库连接串。

## 四、A 第一轮验收整改要求

本节将 A 于 2026-10-22 提出的三项代码级阻断转为实现合同，不改变既有业务服务和工作流边界。

1. **启动前真实员工凭证校验：** 对环境中的员工访问令牌（token）仅计算 SHA-256，再查询一次性隔离库内的 `f05_catalog_employee_sessions_test`，并关联 `employees` 与 `roles`。必须同时满足 `issuer='DISPOSABLE_TEST_ONLY'`、`revoked_at IS NULL`、会话未过期、员工状态为 active、角色代码属于 sales/manager/store_head。只检查 43 位 token 格式不算通过；任一条件不满足或查询失败均失败关闭（fail-closed）。不得保存或记录原始凭证。
2. **启动前当前数据库角色校验：** 在运行时直接查询 `current_database()`、`current_user`、PG 版本和 `pg_roles.rolsuper`。数据库/角色/PG16 身份不符或 `rolsuper=true` 必须拒绝启动。只读复用冻结的 `catalog-readiness.mjs`；不修改它。
3. **硬 tick 截止时间：** 每次 `runOnce()` 最多等待本进程剩余运行时长。超过截止时间即发出稳定错误码 `MATCH_RETRY_TICK_DEADLINE_EXCEEDED`，入口以退出码 124 硬退出，避免仍在运行的 worker 或连接池关闭拖延最大运行时长。worker 领取任务后已经提交的 PostgreSQL lease 是恢复依据；测试必须证明慢任务超时后持久 processing lease 仍在、到期后重启进程能重领并完成任务。不能只用立即返回的 Mock 测试证明该合同。

## 五、验收矩阵

| 验收域 | 必须证据 |
|---|---|
| 配置与环境门禁 | 单元测试证明生产环境、非回环地址、错误数据库、缺失凭证和冲突 Runtime flag 均拒绝；真实 PG16 还须拒绝不存在、过期、撤销、员工非 active、角色不允许的会话 |
| 真 PG16 | 实际服务版本为 16，数据库为 `f05_catalog_test`，角色为 `f05_catalog_ci` 且 `rolsuper=false`；完整现有 schema probe 通过；同一启动入口在该角色被临时提升为超级用户时必须拒绝 |
| 自动执行 | 测试只准备持久队列事实，再启动独立进程；不得直接调用 worker 来冒充调度器成功 |
| 有界轮询 | 每 tick 领取数不超过配置批量；空队列轮询有休眠，无忙循环；慢任务超过最大运行时长 maxRuntimeMs 后，进程入口以 124 退出 |
| 并发与租约 | 两个独立进程同时运行；同一代际不能重复产生 Matching 事件；过期 processing lease 可恢复 |
| 失败与退避 | 来源证据失效时旧结果不被视为 current；失败状态与下一次执行时间持久化；修复证据后由重启进程自动完成重试 |
| 退出与恢复 | SIGTERM 后干净退出；实际 SIGKILL 与超时硬退出均验证持久 lease；lease 到期后重启从 PostgreSQL 状态恢复并防止重复事件 |
| 关联回归 | 运行既有 `engineering/integration/f05-matching-ttl-retry.pg16.test.mjs`，不重跑旧 F05 421 项全包或 66 项 Oracle |
| 代码与范围 | 所有新增 JavaScript 文件 `node --check`、`git diff --check`、差异路径与用途白名单通过 |
| 最终 CI | 最终业务 HEAD 对应的专用 Push Run 完成且成功，失败数与跳过数均为 0 |
| 证据 | Artifact 记录实际 HEAD、Run ID、分支、测试日志和 SHA256 清单；不超过 20 MiB，保留 1 天 |
