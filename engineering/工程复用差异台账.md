## 技术决策

- F01 选用 Node.js >=22.16.0 的内置 HTTP 与测试能力 + npm 锁文件，优先使基础脚手架能够**真实构建、独立测试**；当前并未宣称完成 TypeScript/Fastify/pg 复用验证。
- 实际 PostgreSQL readiness、断库/恢复测试属于 F01-3 的未闭环事项；本批使用注入探针测试 HTTP 状态机，未连数据库时系统固定 `503`，不作假的 ready 成功。
- `main` 治理新文件由 B 通过 main ref 阅读，不拷贝或覆盖 A 的状态控制文件；不修改 C 设计分支。
- 安全测试额外覆盖 `APP_ENV` 与 `NODE_ENV` 双生产保护、公开监听显式授权、探针异常/挂起超时。
- F04 决定当前正式接口框架前，不将旧 218 项 OpenAPI 作为现行可达路由。
