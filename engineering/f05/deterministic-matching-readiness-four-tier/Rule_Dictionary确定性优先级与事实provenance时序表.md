# F05-7｜匹配词典优先级及事实来源

优先级由高到低：具体车型年款、车系年款范围、车系、品牌、全局。**同级冲突**产生指定字段的 conflict，不以更新时间、随机顺序或用户输入替代。已确定条件继续匹配；局部 hard unknown 产生 confirmation_needed，不扩大为通用未知。

同字段多值 OR，跨字段 AND；不存在的条件视为不限。硬条件范围与排除条件必须来自销售的标准匹配描述及合格词典。车辆事实证据优先结构化，其次检测，再次详细描述，最后模糊词；真实上游车型原始事实不得被本地映射缺失覆盖。记录原文本、规则版本、条件、事实来源、解释链、提交时间和失效原因。
