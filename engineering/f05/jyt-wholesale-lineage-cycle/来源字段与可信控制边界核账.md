# F05-3B｜来源字段与可信控制边界核账

## 物理证据及授权

- 正式产品：PDM-04 最终规则第 3～5、11～13、16 节，PDM-02、PDM-06、PDM-09 和 PDM-22 Final。
- 已签物理：M94 vehicles（source_type、source_sale_status、platform_visibility、created_by_employee_id、model_id）和 vehicle_listing_cycles（ended_at、started_at、end_reason）。F05-2 000015 责任授权与 F05-3A 000016 合作成员凭据完全独立，本批不重写。
- 新 CI 000017 仅附加 f05_3b_sync_credentials、f05_3b_api_controls、f05_3b_sync_lineages、f05_3b_control_audit、f05_3b_sync_receipts 和守卫触发器；不得用于生产迁移。
- 来源平台常量 JYT，car_code 是源侧身份键，不能当 vehicle_id、经营归属、员工权限或发布人电话授权；同键锁定当前 vehicle。
- 最小车型来源映射：受信数据必须在真实 PG16 上找到 brand/series/model/year 的一致引用；未映射停留 SOURCE_GAP，不制造可信车型。
- 原始 JYT 登录 Token、电话凭据、发布人 ID、VIN、批发内部价和任何真实图片不在本包 SQL、路由、证据或 HTTPS 回包中。
- 上游 offline 只更新真实在售状态与当前 ListingCycle 结束；再次 active 开新 Cycle；本地 hidden 不可被源同步解除；原有客户/Lock/Waitlist/Transaction 等实体不触碰。
- 已转换名邦车的原 car_code 保留历史身份；后续 JYT 同步抑制，不恢复 wholesale，不新建另一可售批发车辆。一键转名邦真实实施归 F05-3C。
- 三固定接口各有独立开关，在 CI 里通过 System Admin 真实 Session 控制面签发、启停、吊销独立 API 凭据；与系统登录、员工/4S、JYT 及 Collector 电话授权不混用。

## 证据边界和来源缺口

**本包没有真实 JYT/Collector 账号、生产名邦同步控制面、真实外部采集事件或生产 API Credential 的可信来源。** 本轮仅验一次性非生产 PG16 与环回 TLS 中、基于已签 F03 System Admin 身份的控制面授权及独立合成同步凭据。

生产缺口维持 SOURCE_GAP_BLOCKED_FOR_PRODUCTION：不能凭 CI 绿色宣告真实第三方接入可信、真实 API 可用、批发供应真已核对或 F05 全域上线。A 以后须单独签署生产集成来源与真实第三方联调授权。
