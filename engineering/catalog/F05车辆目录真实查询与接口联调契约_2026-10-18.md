# 名邦汽车 V1｜F05车辆目录真实查询与接口联调契约

> 工程状态：**非生产测试版实际Node HTTP＋真实PostgreSQL 16，未授权线上接入**。本文件描述已经在GitHub运行成功的功能，不是客户端C01已联调的声明。

## 1. 已实现实际路径

1. `GET /api/v1/catalog/vehicles`：在实际PG16的vehicles、vehicle_models、vehicle_brands、vehicle_series、vehicle_listing_cycles、可销毁测试可见性与保护侧表中执行参数化查询，先过滤再分页。
2. `GET /api/v1/catalog/vehicles/:vehicleId`：只查当前公开合格ListingCycle；任意隐藏、下架、已售、Priority隔离等保护失败返回404，不返回内部数据。

服务仅支持`APP_ENV=test`、`NODE_ENV=test`、精确同意标志、127.0.0.1、非超级用户`f05_catalog_ci`及独立库`f05_catalog_test`。**临时测试可见凭据由隔离回归创建，不具有生产公信力。**

## 2. 列表查询合同

| 参数 | 已实现安全规则 |
|---|---|
| `source` | `wholesale`（默认）、`mingbang`、`four_s`三类之一 |
| `region` | 仅`national`；城市/周边真实数据源未建立，其他值拒绝 |
| `pageSize` | 固定15，不接受任意放大 |
| `sort` | `newest`真实成功；六项其他PDM20合法排序目前返回503；不合法`oldest`返回400 |
| `modelId` | 可选真实车型ID，字符型PG BIGINT安全上限校验，无模糊匹配 |
| `brandId` | 可选真实品牌ID，使用车型品牌或受信车系父品牌 |
| `seriesId` | 可选真实车系ID，与品牌/车型联合精确约束 |
| `cursor` | HMAC V3签名，绑定来源＋排序＋车型＋品牌＋车系＋当前上架周期的微秒时间及ID，跨条件复用返回400 |

合法查询示例：

```http
GET /api/v1/catalog/vehicles?source=wholesale&brandId=59001&seriesId=59001&modelId=59001&sort=newest
```

返回JSON：`items`、`nextCursor`、`pageSize=15`、`source`、`sort`、`region=national`、`modelId`、`brandId`、`seriesId`、`productionReady=false`。车辆对象仅可输出`vehicleId,listingCycleId,source,listingStartedAt,modelId,price:null,priceState,catalogState`，严格不含VIN、批发价/成本价、批发发布人电话或其他客户身份。
