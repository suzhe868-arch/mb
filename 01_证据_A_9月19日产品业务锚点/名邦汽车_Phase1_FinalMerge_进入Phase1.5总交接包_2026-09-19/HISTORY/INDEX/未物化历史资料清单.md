# 当前未能物化的历史资料清单

本清单的含义是：

> 文件/材料被确认存在或在项目交接中被明确要求回查，但当前运行环境无法将其实体字节直接从 File Library 导出到本 ZIP。

这不是“可以忽略”。

Phase 1.5 的第一步必须继续寻找这些材料：

- CN11 当前唯一业务基线包；
- 业务重审主线换代交接包 V2；
- R1～R5 原分支交付包；
- C1～C5 原始冻结包；
- 图片模块完整最终变更包；
- 旧 IA CHECKPOINT；
- 旧业务矩阵 / Page Inventory / Action Matrix；
- 旧低保真；
- 旧 Decision Register / Audit Matrix；
- 已废弃规则 / Superseded Register；
- 其他旧 SSOT / CURRENT / Handoff。

处理方式：

- 找得到实体原件 → 放入 Phase 1.5 历史证据池；
- 找不到原件 → 根据 CURRENT 与已确认索引继续，但标记 `HISTORY_SOURCE_NOT_MATERIALIZED`；
- 不得因为没找到原件就把模型记忆当成完整原文。
