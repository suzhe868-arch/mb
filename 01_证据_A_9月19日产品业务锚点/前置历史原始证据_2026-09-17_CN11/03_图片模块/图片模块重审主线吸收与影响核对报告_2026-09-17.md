## 二、主线影响结论

### MATCH

- 人工名邦/4S 允许 0 图正式发布；无图使用统一占位图，图片不是发布硬条件。
- 图片故障不回滚已经成功创建的新名邦车，不影响 Matching / Priority / Lock / Transaction。
- `vehicle_conversions` 永久保存批发→名邦来源关系。
- 图片变化不新建 listing cycle；上下架不应重置已形成的图片业务资产。
- 当前 `vehicle_images` 已有 `upstream_url / local_object_key / sort_order / upstream_image_id / upstream_car_id / content_hash / retry_count / last_error` 等基础字段，可作为后续整改基础。
- Vehicle Read 已有 `VehicleImageUrlResolver` 抽象，方向上符合“客户端不直接暴露对象存储内部地址”，但真实 resolver 尚未实现。

### CONFLICT

1. **普通批发图访问模型**：CN10 仍以“保存上游 URL + 名邦图片代理，图片代理不等于永久存储”为主；新规则要求“首次入库即本地化第一张可用封面，其余图片在真实查看/预加载时按需永久吞入名邦服务端对象存储”。
2. **首次图片集合**：新规则要求首次入库 `images[]` 形成冻结快照，后续上游新增/删除/改排序都不再同步；CN10 尚未冻结这一口径。
3. **转换下载策略**：CN10 写“读取全部金鱼塘图片 URL 并异步迁移”；新规则要求已吞图不重下、正在吞任务复用、只迁未本地化图片。
4. **转换失败图片重试**：CN10 Decision/Async Contract 仍写“失败 items retry”；新规则取消复杂转换重试，转换后缺图由销售按普通名邦车人工补图。
5. **转换状态语义**：CN10 `ConversionDTO.image_migration_state` 使用 `pending/success/partial_failed/failed`，`image_migration_jobs` 使用 `processing/success/partial_failed/failed`；新冻结规则要求 `failed` 只表示车辆本身未成功转换，车辆已创建但图片不完整为 `partial_failed`。当前 DTO/DB 语义必须施工时重新对齐。
6. **已吞图片所有权**：新规则要求物理文件所有权从原批发车转给新名邦车，原批发车只保留来源历史且不再持有 `local_object_key`；当前 DB/Conversion 没有这套事务模型。
7. **上游图片身份唯一键**：当前 `uq_vehicle_images_upstream_identity(source_platform, upstream_image_id)` 是跨车辆唯一。若转换后目标名邦车继续保留来源元数据、原批发车也保留来源历史，当前结构无法直接同时表达，需要施工时决定“历史表/来源引用/唯一键作用域”的正确实现，不能直接复制同一物理引用。

### NOT_IMPLEMENTED

- wholesale 首次图片快照冻结写侧；
- 首张可用图首次入库本地化和 fallback；
- 详情第 2/3 张处理、第 4 张预取及前向约 2 张窗口；
- viewer 响应与对象存储共用一次上游回源数据；
- 对象存储成功 + DB 成功才算已吞；DB 失败后删除新对象；
- 同图 single-flight、单车并发上限 3；
- 单图每轮最多 3 次退避重试、后续真实查看开启新一轮；
- 失败图片从可见图集暂时跳过并按原排序恢复；
- 已吞图本地 404/损坏后的受控自愈；
- 真实 image proxy/object-storage resolver；
- 真实默认 placeholder 返回路径；
- 人工名邦/4S 图片上传、删除、拖动排序 API 与实现；
- 一键转名邦 handler/worker、single-flight 复用、物理文件所有权转移；
- 转换后普通名邦车图片删除的物理对象删除；
- 本包要求的 19 组真实行为测试。

## 四、跨模块冲突检查

未发现与当前已冻结的以下规则产生新业务冲突：

- hidden 车辆仍参与 Matching；图片失败不得改变车辆 Matching 资格；
- Priority 只控制临时独占与可见性，不因为图片吞取改变 Priority 状态；
- Recommendation/visibility grant 仍决定 hidden 车辆客户可见性，图片 URL 不得绕过 Vehicle Read 授权；
- Lock / Transaction 状态不受图片失败影响；
- listing_cycle 不因图片增删、吞图、本地化或恢复产生新周期；
- 人工车 0 图正式发布继续有效；
- 一键转名邦“原批发隐藏、新名邦车按转换时真实可见状态决定初始展示”的主业务规则不变。

结论：**没有新的产品待裁决冲突。**
