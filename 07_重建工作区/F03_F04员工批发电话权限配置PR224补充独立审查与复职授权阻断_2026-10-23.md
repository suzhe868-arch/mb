## 三、新增阻断：PDM-02 §9.4 禁止员工复职后自动恢复旧权限

正式规则文件 `07_重建工作区/PDM-02_最终完整规则.md` 第 9.4 节规定：员工从 inactive 恢复 active 后，必须按当前角色、permission、data scope 重新授权；**不得自动恢复 inactive 前 permission**。

当前 PR 的 `PublisherPhoneAdminService.get()` 只在响应投影中将不合格员工的 `enabled` 暂时设为 false；它没有持久结束既有 phone-special scope binding，也没有撤销本 API 对应的 override 或关闭持久 `employee_mode.enabled`。因此：

1. System Admin 授予员工电话专项权限。
2. 员工被其他合法流程改为 inactive。
3. 在 inactive 期间不调用本 API。
4. 员工被重新设置为 active。
5. 旧 override、binding、mode 仍然存在，下一次 GET 会再次报告 enabled。

该行为违反 PDM-02 §9.4；只在 inactive 时暂时返回 false 不能满足规则。对会导致当前权限失效的不合格角色变更，也应防止资格恢复后旧授权未经重新授予便自动复活。
