   历史与真实页面支持该动作，但当前 Navigation / Action Contract 曾明确写 `no model creation is inferred`，属于真实承载冲突。

4. **本地车型节点挂错父级后的修正、重复车型合并、旧节点退出与轻量合并历史、真实旧车型长期保留。**

5. **不设计车型名称 alias / 同义词、不设计“同一车型多个 JYT 编号”的额外机制、不设计人工单车车型锁定。**

6. **选择具体车型后自动带出年款、排量、变速箱、排放、能源等固定属性的完整边界。**
