## 二、A 已签技术裁决

1. 用户已明确批准 PDM-09 的电话访问产品边界：PC 后台按员工单独授予既有 `publisher.phone.sensitive`，并二选一配置 `LOCKED_ONLY` 或 `ALL_ACTIVE_JYT`。批发车来自批量采集，不要求逐车指定销售负责人。
2. A 批准仅将以下三个既有动作映射到同一个 `publisher.phone.sensitive` 能力：`vehicle.publisher_phone.read`、`vehicle.publisher_phone.latest`、`vehicle.publisher_phone.dial`。不得新增 `can_call_wholesale_phone`，不得将批准扩展到其他权限或业务动作。
3. 上游电话读取、取最新电话和拨号只适用于当前仍为 wholesale/JYT 的车辆。**电话访问不得要求 F05 转换记录**；车辆转为名邦/4S 后应拒绝原上游电话入口。
4. 两种模式是此敏感能力的专项范围，不能扩张员工通用车辆经营 data scope：
   - `LOCKED_ONLY`：当前车辆必须为有效批发来源，且存在与当前车辆/当前 listing cycle 关联、状态有效、尚未取消且未过期的正式 Lock。LockRequest 申请中、拒绝、取消、过期或旧 cycle 的 Lock 均不算。
   - `ALL_ACTIVE_JYT`：当前车辆按现有状态口径仍为在售 wholesale/JYT；无需先有 Lock 或 Transaction。已转名邦/4S 或已下架车辆拒绝。
5. 每次敏感动作必须读取当前 Employee 身份/状态、当前权限目录、角色模板/个人 override（个人 deny 优先）、当前专项范围与车辆来源/状态；撤权、停用、切换模式或 Lock 到期立即影响下一次请求。
6. 真实 JYT/Collector、真实电话来源、CDN/OSS、Feishu、生产和资金均不在本任务授权内。不得把合成测试结果描述成真实外部集成或生产可用。
