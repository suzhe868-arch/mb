# 3. Batch 1｜稳定一致项｜重新展开版

### P08-A01｜首次图片集合冻结

批发车第一次入库时读取当次 `images[]`，保存图片身份、首次 `upstream_url` 和原始顺序，形成冻结快照。

后续普通 JYT 同步：
- 不因为上游后来新增图片而补入；
- 不因为上游删图而从本地集合删除；
- 不因为上游换排序而改本地原始排序；
- 单张冻结 URL 后续失效，只处理该图片自身失败 / 恢复；
- **不得因为单张 URL 失效重新同步整车图片集合。**

状态：`USER_REVIEW_PENDING`

### P08-A02｜首次列表封面、本地化 fallback 与占位图

批发车首次入库即按冻结原始顺序尝试生成列表封面：

1. 先尝试原始第一张；
2. 第一张失败，继续向后寻找第一张成功本地化图片；
3. fallback 只改变当前展示封面，不改变数据库原始排序；
4. 原第一张以后恢复成功时，可重新成为原排序首图；
5. 上游 0 图或全部图片失败，都不阻止车辆入库、匹配、销售 / 在售；
6. 没有可用真实图时使用统一默认占位图。

状态：`USER_REVIEW_PENDING`

### P08-A03｜名邦受控图片地址与可配置域名

批发 / 报告静态图片的业务数据只保存图片 path，不把前端公开域名或上游回源域名写死进数据库。

具体：
- 客户端、员工端不得直接使用上游图片域名；
- 对外图片地址由“名邦可控公开图片域名 + 配置前缀 + 图片 path”生成；
- CDN 未命中缓存时，再根据配置的上游图片源站域名 + 同一 path 回源；
- 当前标准上游图片源站配置使用 `img.jytche.com`；
- 名邦公开域名、路径前缀、JYT 图片源站域名均作为配置项，可后续替换；
- 完整 H5 / 报告页面不套用普通图片 path 规则。

### P08-A06｜什么才算“已本地化”以及失败事务边界

图片只有同时满足：

1. 名邦对象存储保存成功；
2. DB 成功写入有效本地对象标识；

才视为真正“已本地化”。

异常处理：
- 对象存储成功、DB 最终失败 → 删除刚保存的新对象，避免孤儿文件；
- viewer 已经成功看到上游图片，但随后服务端持久化失败 → **本次客户体验不回滚**；
- 这种情况下数据库仍将该图片视为“未本地化”，以后按正常规则再次处理。

状态：`USER_REVIEW_PENDING`

### P08-A07｜本地优先与受控自愈

已经成功本地化的图片：

- 正常访问永久优先使用名邦本地资产；
- 不再每次读取都重新检查 JYT 原图；
- 冻结 `upstream_url` 继续作为来源 / 极端恢复依据；
- **只有确认名邦本地对象损坏、丢失或 404 时**，才允许用冻结 URL 做受控自愈；
- 自愈单张图片不触发整车图片重新同步。

状态：`USER_REVIEW_PENDING`

- 当前失败图暂不占详情可见图片位置；
- DB 图片来源记录和原始排序永久保留；

# 8. 2026-10-03 CDN URL 生成补充裁决

### P08-CDN-01｜图片路径与域名配置

用户确认：采集到的图片原始数据本身不包含固定域名，核心事实是图片路径。

因此普通图片类资源统一采用：

- 数据库只保存图片 path，例如：
  `/user/370436/report/image/1788072135101_1352.jpeg`
- 不在业务数据中写死名邦前端图片域名；
- 不在业务数据中写死 JYT 图片回源域名；
- 前端公开图片地址由“名邦可控公开图片域名 + 固定前缀 + 图片 path”运行时生成；
- CDN 回源地址由“配置的上游图片源站域名 + 图片 path”运行时生成。

示意：

```text
DB:
  /user/xxx/xxx.jpg

Frontend public URL:
  {PUBLIC_IMAGE_DOMAIN}/{PREFIX}/user/xxx/xxx.jpg

CDN origin:
  {JYT_IMAGE_ORIGIN}/user/xxx/xxx.jpg
```

当前示例可表现为：

```text
前端：
https://img.mingbang.com/ct/user/xxx/xxx.jpg

CDN 回源：
https://img.jytche.com/user/xxx/xxx.jpg
```

但 `img.mingbang.com`、`/ct/`、`img.jytche.com` 均属于可配置项，不冻结为数据库永久字段。

适用范围：
- 车辆相册图片；
- 出险记录图片；
- 4S 维保报告内静态图片；
- 其他报告静态图片；
- 后续同类采集图片附件。

例外：
- 完整报告 / H5 链接（如 `app.yutangkeji.com/#/detail/...`）不套用普通图片 path 规则，继续按完整报告 URL / report proxy 规则处理。

状态：`USER_APPROVED`


### P08-CDN-02｜资产化后公开图片 URL 保持不变

用户确认：
