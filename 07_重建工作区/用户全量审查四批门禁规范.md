# 名邦汽车 V1｜用户全量审查四批门禁规范

> 状态：`ACTIVE / HARD_GATE`  
> 日期：2026-09-23  
> 适用范围：PDM-01～PDM-25 全部产品域。

## 1. 唯一原则

任何规则原子都必须经过用户本人审查。

模型判断为“稳定一致”不等于用户已确认；`FROZEN` 不等于当前最终采用；“明确废弃”也必须由用户过目确认。

所有未审规则统一：

`USER_REVIEW_PENDING`

## 2. 每个 PDM 的四批审查

| 批次 | 内容 | 是否必须用户审查 |
|---|---|---|
| Batch 1 | 稳定一致、建议直接保留 | 是 |
| Batch 2 | 明确废弃、明确替代、DO_NOT_RESTORE | 是 |
| Batch 3 | 明确知情修改、后续明确新增 | 是 |
| Batch 4 | 冲突、历史遗漏、证据不足、新业务选择 | 是 |

## 3. 每批输出格式

每个规则原子至少展示：

1. Atom ID；
2. **拟进入最终基线的完整规则文字**；
3. 证据结论（简短）；
4. 模型分类；
5. 模型建议；
6. 用户审查状态。

用户可回复：

- 本批全部通过；
- 第 X 条修改为……；
- 第 X 条不同意；
- 第 X 条暂缓。

## 4. 硬停止

每批展示完必须停止等待用户。

未经用户确认，不得：

- 自动进入下一批；
- 生成该域最终规则；
- 标记 COMPLETE；
- 进入下一个 PDM。

## 5. 四批之后还有一次最终总览

四批全部通过后，生成该 PDM 完整、自包含的最终规则草案，再由用户整体复核一次。

只有最终总览也通过，才能：

> Decision Register → 正式中文基线 → 状态 COMPLETE → commit → 下一 PDM

## 6. 证据规则

任何审查项都必须能回到原始仓库证据。

禁止用前一轮摘要替代原始证据继续推导。

固定链路：

> 原始证据 → 规则原子 → 四批用户审查 → PDM最终总览 → 最终基线
