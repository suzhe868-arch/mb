## 五、四域接线要求

### R01｜Collector 发布人电话回传

- 回调方向保持 Collector→名邦，不恢复名邦直接调用 JYT 电话 API 的旧方向。
- 缓存身份严格使用 `source_platform + upstream_publisher_id`，不得改用 `car_code`、单车 ID 或手机号。
- 仅允许本任务合成回调凭据、合成发布人 ID 和 `TEST-123456` 类不可拨测试值；验签、时钟窗口、nonce/幂等、重放、乱序、同 Key 异 Payload 与事务回滚必须有真实 PG16 证据。
- 读取/latest/dial 每次都必须复核当前员工、Session、scope、Vehicle 当前 `source_type=wholesale` 与上游电话敏感能力。
- 当前签名 F03 能力目录未能证明 `publisher.phone.sensitive` 合法正向授权时，保留 `TECH_ALIAS_PENDING_A/SOURCE_GAP` 并拒绝；不得新增或批准业务权限，不得把 CI 合成号码标为真实号码。

### R02｜图片 path、受控 CDN 与资产化接口

- 公开 URL 只能由受控配置域名、配置前缀与经过规范化的相对 path 生成；禁止客户端直接收到 JYT 原始 URL，禁止路径穿越、任意域名和 SSRF。
- 保留 PDM-08 图片首次冻结、原始顺序、单图恢复、零图占位、报告/H5 私有资源分离，以及车辆转换与图片资产化解耦。
- 在本包可销毁 PG16 中，验证对象写入与数据库 `object_key/path` 双成功、失败补偿、重复幂等和并发保护；只允许注入的本地测试存储/CDN Adapter，不允许真实网络。
- 没有合法签名转换来源时，不创建可信资产化任务；必须保留 `F05_CONVERSION_POSITIVE_SOURCE_GAP`，不得用合成 Vehicle/ListingCycle/Transaction 伪装正式来源。

### R03｜可信父来源与权限门禁

- 每个敏感请求重新读取已签 F03 Session/Permission/Scope/Object 与当前 F05 父事实；不得缓存旧授权，不得把本地布尔值、合成数据库读或前置语法拒绝标成 `SIGNED_PARENT_VERIFIED`。

- 保留 `SIGNED_PARENT_VERIFIED`、`SIGNED_PARENT_NEGATIVE_ONLY`、`CI_SYNTHETIC_ONLY`、`SOURCE_GAP` 四类来源区分。
- F05 转换正向源仍缺失时，不得自行创建父签名正例或修改冻结 F05 源码、迁移和父签名表。

### R04｜通知、SLA、DND、Incident 与 Feishu 边界

- 只消费 PDM-23 allowlist 内的事件；通知不改变 Customer/Consultation/Lock/Waitlist/Transaction/Refund 等源业务状态。
