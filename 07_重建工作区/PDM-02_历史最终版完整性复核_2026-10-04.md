## 2. System Admin 与 Customer 账号停用最终边界

1. Customer 停用 / 恢复仍使用 `customer.account.disable` 作为名邦员工侧受控 capability。
2. System Admin 可以直接执行该动作，因为它被定义为控制平面治理动作。
3. System Admin 因此不会获得 Customer owner、销售接客能力、CRM 业务执行权、Lock / Transaction 等业务执行权。
4. 经理 / 店长等 active 名邦员工执行时必须同时满足 `customer.account.disable + Customer data scope`。
5. 普通销售默认关闭，可通过当前角色模板 / 个人明确授权开放。
6. 4S 成员 hard DENY。
7. 停用 / 恢复必须审计。

本结论同步形成 `PDM01-DEC-A16-R2`，显式覆盖上一轮 PDM-01 审计中“System Admin 仅配置、不直接执行”的窄解释。
