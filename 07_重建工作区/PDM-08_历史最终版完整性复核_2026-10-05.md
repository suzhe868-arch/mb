## 2. 分享卡片价格安全

车辆分享卡片保持简单：

- 车辆主图；
- 完整车型名称；
- 已批准的客户安全静态字段；
- 轻量 CTA。

明确不得固化：

- 客户展示价；
- 任何动态 / 受权限价格；
- 内部批发价 / 上游批发价；
- VIN；
- 上游发布人电话；
- 内部状态；
- 其他仅内部可见字段。

真正打开详情后，再按接收人的当前身份、权限、价格权益和车辆当前状态实时计算展示。

## 3. 报告 / H5 URL 访问边界

名邦受控报告域名、历史 URL、CDN 缓存都只是技术访问载体，不构成永久业务授权。

每次读取出险/维保/其他报告资源时继续重验：

- 当前 Vehicle Read / Visibility；
- PDM-07 当前 customer_visible；
- 敏感原件 / 内部资料 DENY；
- 当前访问者身份与 data scope。

过去拿到过 URL 不等于未来持续可访问。

## 4. 3A｜资产化未闭环期间临时受控回源

用户最终选择 3A：

> **批发→名邦 source_type 转换已合法完成，但图片仍 processing / partial_failed / failed 时，未成功资产化图片允许基于冻结 JYT 来源事实，通过名邦受控 CDN 临时回源 JYT。**

具体：

- 已资产化成功图片立即使用名邦自有对象存储；
- 未成功资产化图片可在任务未闭环期间临时受控回源；
- 客户端/员工端不得获得 JYT 原始 URL；
- 临时可展示不等于资产化 success；
- 失败项仍必须保留并继续重试；
- 资产化成功后立即切自有对象存储，不再日常依赖 JYT；
- 上游临时回源也失败时，该图跳过或占位；
- 不回滚 source_type / vehicle_id / listing_cycle / Favorite / Recommendation / Lock / Transaction；
- 禁止把临时过渡机制实现成名邦车长期依赖 JYT。
