## 4. 真实浏览器验证（不是静态关键字扫描）

- 工具与环境：`Chromium headless`，`Playwright`，加载**带 data URI 高清照片**的离线 HTML 评审页面，以 `320×844` / `390×844` 四个容器，实际浏览器完成排版和截图。
- 四种状态分别渲染：`320/full`、`320/compact`、`390/full`、`390/compact`。
- 两种身份投影被显式覆盖：320px 示范普通 LIMITED 批发列表**无数字客户价**；390px 示范有合法客户价的 UNLIMITED 账户显示紧凑示例数字价 `18.6万（模拟）`。数值不是真车报价。
- 浏览器 DOM `getBoundingClientRect` 和 `scrollWidth/clientWidth` 检查：**四态全部无横向溢出**；车型标题 `text-overflow: ellipsis` 生效；连续车辆 Feed 不生成宽价格列。
- 图片检测：每一态 3 个 `img` 元素，全部 `complete=true` 且 `naturalWidth=710`，`object-fit:cover`，可见照片宽高比约 `1.33`。
- 入口检测：每态均存在 **3 个来源频道、6 个主筛选、3 项底部导航**；完整态有合法 Banner 模块，紧凑态该占高模块 `display:none`；完整/紧凑均含搜索。
- 静态触控可用性排版指标：实际 CSS 搜索高度 44px、来源频道高度 44px、筛选单项高度 44px（属于 H01 设计尺寸，不证明运行小程序可触控或权限能用）。
- 车辆信息列可用宽度：320px 约 **161px**、390px 约 **204px**（实际 `getBoundingClientRect`）。
- 四个状态真实检查 **PASS 4/4**；单独 PNG、整体 PNG 及 JSON 输出文件已在此会话生成。
