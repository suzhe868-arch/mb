## 4. 上层规则的重点负例

1. 批发 LIMITED 列表无数字价；主动进入详情有价有额自动解锁，不引入“点击查价”；额度耗尽未解锁 `--万`、真正无数字价“价格咨询”；UNLIMITED 有价直接可见。
2. 首页只三底部一级 Tab，不因收藏存在而新增“收藏”一级入口；无真实数据不画“已检测/严选/高性价比/质保”营销事实。
3. C 锁车按钮只创建/复用 LockRequest.PENDING；同车合法竞争 `LOCK_CONFLICT` 自动候补；不保证名次，不直接成立 Lock。
4. E02-02 多草稿有效输入自动保存、空白不建草稿；无手工保存按钮；4S hard DENY 对名邦 LockRequest 审批。
5. PC System Admin 不是默认 Employee 业务操作者，缺权限敏感按钮不可仅灰化；旧 Collector 连接/电话测试页禁止恢复。
6. A/B 旧视觉方向不是当前待用户选择项；方向已经确认，评审还需要看新版页面排版与品牌色调整。
