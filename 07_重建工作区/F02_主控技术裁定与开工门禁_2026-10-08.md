## 3. 特别禁止及待测风险

1. 历史 `scripts/db-migrate.mjs` 的 SQL 与 schema_migrations 记录不在同一事务；历史 `scripts/db-clean-rebuild.mjs` 含 `DROP SCHEMA public CASCADE`。禁止把旧脚本当 F02 合法迁移器。
2. PDM-05 车型三级字典 `品牌→车系→具体车型`，年款是具体车型属性；source mapping 是 JYT↔local 关系，不能用名称或强制相同 ID 替代。
3. PDM-06 草稿允许同员工多条自动保存；人工 VIN 可选，填了 VIN 只在规定人工正式车范围精确校验，不能无差别建立全源 VIN 唯一约束。
4. PDM-18 `LockRequest` / `Lock` / `Waitlist` 独立；申请 PENDING 6h 不占车、成功 Lock 只允许一个；合法竞争申请自动进入候补，但资格/手机号/车辆周期等仍重验。
5. PDM-19 Refund 主态 `pending/refunded/closed`；`closed+close_reason` 不代表真实退款；退款 Lock XOR Transaction、余额与并发必须完整校验，不能只用数据库 CHECK 表达全部资金安全。
6. Vehicle/Source/listing_cycle/Priority/Recommendation/grant 等必须保持当前独立事实，不借 F02 将 hidden 等于 offline、Priority 等于 grant。
7. 全部真实 Schema/DDL、完整数据资产导入、运行期权限/路由、旧库兼容、断库重试/并发的测试尚**NOT_RUN**；F01 的 `13/13 + 5/5` 健康测试不能作 F02 通过证据。
